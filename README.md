# SolarAI Analytics · HeliOS

Landing pages, published with GitHub Pages:

- `solar-ai/`: SolarAI Analytics, the performance analysis service for solar farms (EN/ES). It also presents HeliOS as our product.
- `helios/`: HeliOS, the O&M platform (3D digital twin from SCADA, work orders, inventory, field app and Apollo, the AI assistant).
- `index.html`: links to both.

All figures in the SolarAI demo come from a fictitious plant with data we generated; they do not belong to any real project. HeliOS screenshots hide the plant name and location.

Static HTML, CSS and JS only: no build step. To preview locally, serve the folder with any static server and open `/solar-ai/` or `/helios/`.

Contact forms send to hello@solarai.com.au through FormSubmit.
